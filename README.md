# BEC Content & Lead Tracking app

Browse BEC Integrated Solutions products, keep track of enquiries, and export a
lead list without setting up a server or sharing account credentials.

- [`webapp/`](./webapp/) contains the product catalog, representative product
  images, and lead tracker.
- [`.github/workflows/pages.yml`](./.github/workflows/pages.yml) publishes the
  static app to GitHub Pages.
- [`.github/workflows/ci.yml`](./.github/workflows/ci.yml) checks the catalog
  and required app files.

Try the live app at <https://calina-miguel.github.io/BEC-Content-Lead-Tracking-app/>.
See [`webapp/README.md`](./webapp/README.md) for the demo steps and data limits.
